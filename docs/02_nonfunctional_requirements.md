# Нефункциональные требования (НФТ)

### NFR-01: Производительность
- Система должна обрабатывать и синхронизировать базы объемом до миллионов контактов.
- Обработка ежедневной пачки сигналов и рассылка уведомлений в CRM должна выполняться в течение 1-2 часов для обеспечения условия "мгновенной" отправки.

### NFR-02: Безопасность
- Все передаваемые данные должны шифроваться с использованием TLS 1.2+.
- Для передачи файлов с поставщиками должен использоваться только SFTP.
- Номера телефонов в базе мониторинга должны храниться в виде хеша (SHA-256).
- Система должна обеспечивать хранение учетных данных (API-ключи, SFTP-пароли) в зашифрованном виде.
- Доступ к данным строго в соответствии с ролевой моделью. Маркетологи не должны иметь доступа к персональным данным.

### NFR-03: Надежность
- Время бесперебойной работы (Uptime) должно составлять не менее 99.5%.
- Процессы загрузки и обработки данных должны иметь механизм повтора при сбоях.

### NFR-04: Совместимость
- Система должна быть реализована как веб-приложение, совместимое с последними версиями браузеров Chrome, Firefox, Safari.
- API интеграции должно соответствовать спецификациям Bitrix24 REST API.
