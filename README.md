# Платформа «Живая База» (KNAM) - SRS
**Версия:** 1.0

## 📝 Описание проекта
Система KNAM представляет собой B2B-платформу, которая интегрируется с CRM-системами клиентов (на примере Bitrix24) для мониторинга активности их клиентской базы. Система загружает контакты, фильтрует их, передает на проверку внешним поставщикам данных и возвращает в CRM уведомления о возобновлении интереса клиентов в режиме, близком к реальному времени.

## 👥 Роли пользователей
*   **Администратор KNAM:** Технический специалист клиента. Настраивает интеграцию, правила фильтрации, управляет доступом. Имеет полный доступ к данным и аналитике.
*   **Маркетолог/Пользователь KNAM:** Бизнес-пользователь. Анализирует эффективность кампаний через дашборды. Не имеет доступа к персональным данным (номерам телефонов). Видит только обезличенные ID и агрегированную статистику.
